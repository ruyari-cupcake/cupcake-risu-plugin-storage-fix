🧁 컵케익 리스 플러그인 저장소 고치기 v__RPF_VERSION__

리스(RisuAI)의 플러그인 저장소 목차가 사라지면, 리스는 데이터를 덮어쓰지 않으려고 모든 플러그인의 저장소 요청을 Failed to load plugin storage index 오류로 거부해요. 새로고침이나 플러그인 재설치로는 풀리지 않고, 리스에는 이걸 고치는 메뉴가 없어요. 이 도구는 리스 탭 안에서 그 상태를 확인하고 고쳐 줘요.

이런 증상이면 써 보세요

  • CPM 패널에 🗄️ "리스 플러그인 저장소가 열리지 않아요" 안내가 떠요.
  • 개발자 도구 콘솔에 Failed to load plugin storage index가 보여요.
  • 플러그인 설정·기록이 새로고침할 때마다 저장되지 않거나 불러와지지 않아요.

하는 일

  1. 목차 파일(플러그인 데이터를 어디에 뒀는지 적어 둔 파일)이 정말 없는지, 또는 손상됐는지 브라우저 저장소에서 직접 확인해요. 정상이거나 확실하게 읽지 못하면 아무것도 바꾸지 않아요.
  2. 살아 있는 예전 목차를 찾아요. 있으면 시점을 골라 되살리기 — 그 시점의 플러그인 데이터가 돌아와요. 되살린 뒤에는 리스가 오래된 정리 대상 파일을 지울 수 있어서, 다른 시점으로 다시 바꾸기는 어려워요.
  3. 없으면(또는 원하면) 초기화 — 없는 목차를 가리키는 표시 하나만 지우고, 플러그인 저장소가 새로 시작해요.
  4. 리스가 그 변경을 저장 파일에 실제로 기록했는지 확인한 뒤에 새로고침 버튼을 보여 줘요.

도구가 직접 바꾸는 건 리스 데이터베이스 안의 표시(_coldpluginIndex) 하나뿐이에요. Risu 계정 저장 모드가 아니면 아무것도 인터넷으로 보내지 않아요 (계정 저장 모드에서는 리스가 쓰는 계정 서버에, 이 기기의 리스 로그인으로, 리스와 같은 읽기 요청만 보내요). 초기화해도 캐릭터·채팅·설정, 리스에 설치된 플러그인과 그 설정값, 플러그인의 로컬 저장소는 그대로예요. 새로 시작하는 건 플러그인이 플러그인 저장소에 넣어 두던 데이터(예: CPM 사용량 기록)예요. 리스 플러그인 저장소는 플러그인끼리 나눠 쓰는 한 칸이라서, 특정 플러그인 몫만 골라 지울 수는 없어요.

쓸 수 있는 곳

  • ✅ 브라우저에서 쓰는 리스 — risuai.xyz(Risu 계정 저장을 쓰지 않을 때), 직접 올린 웹 빌드, 포크 리스
  • ✅ Risu 계정 저장 모드 (0.2.0부터) — 계정 서버에 직접 물어서, 잠깐 서버 문제인지 정말 고장인지 구분해요. 서버가 응답하지 않거나 확인을 끝까지 못 하면 아무것도 바꾸지 않아요. 고치기 전에 다른 기기(휴대폰·다른 컴퓨터)와 다른 탭의 리스를 모두 닫아야 해요 — 고친 내용이 같은 계정의 모든 기기에 반영돼서예요.
  • 🚫 자체 서버(노드) 리스, 데스크톱 앱 — 지원하지 않아요 (Risu 계정 저장을 켜 둬도 마찬가지예요).
  • 🚫 http:// 사설 주소처럼 브라우저 저장소(OPFS)를 쓸 수 없는 곳, 압축 풀기를 지원하지 않는 옛 브라우저 — 도구가 저장소를 읽을 수 없어서 안내만 해요.

계정을 썼다면 먼저: Risu 계정 로그아웃이나 "계정에 저장" 끄기를 한 뒤 이 증상이 생겼다면, 최신 플러그인 데이터는 계정 쪽에 남아 있을 수 있어요 (로그아웃한 상태에서는 도구가 계정 쪽을 확인할 수 없어요). 되살리기나 초기화 전에 다시 로그인해서 계정 데이터를 불러오는 것부터 해 보세요 — 그 뒤에 도구를 실행하면 계정 서버 쪽을 확인해요. 이 브라우저에 그런 흔적이 있으면 도구도 경고를 띄우고 후보를 미리 골라 두지 않아요.

실행 전: 다른 리스 탭은 모두 닫고(계정 저장 모드면 다른 기기의 리스도), 리스 탭을 새로고침한 직후에 실행해 주세요.

1. PC — 북마클릿

  1. 북마크바를 켜고(Ctrl+Shift+B) 아래 버튼을 북마크바로 끌어다 놓아요.
  2. 리스 화면이 다 뜬 탭에서 그 북마크를 눌러요. 오른쪽 위에 패널이 뜨고 바로 상태를 확인해요.
  3. 안내에 따라 되살리기 또는 초기화 → 지금 새로고침.

🧁 플러그인 저장소 고치기

2. 모바일 — 짧은 로더 북마클릿

폰에서는 긴 코드가 붙여넣는 중에 잘릴 수 있어서 짧은 로더를 써요. 로더는 실행할 때 이 사이트에서 최신 도구를 불러와요(인터넷 연결 필요, PC에서도 똑같이 동작해요).

  1. 아래 코드 복사를 눌러요.
  2. 아무 페이지나 북마크로 저장한 뒤, 북마크 수정에서 이름을 저장소고치기로, 주소(URL)를 복사한 코드로 바꿔요.
  3. 리스 탭의 주소창에 저장소고치기를 입력하고, 목록에 뜬 북마크(별 모양)를 눌러요. 주소창에서 실행되지 않으면(아이폰 사파리 등, 직접 확인은 못 했어요) 북마크 목록을 열어 직접 눌러 보세요.

인터넷 없이 동작하는 긴 버전이 필요하면 bookmarklet.txt(약 __RPF_BOOKMARKLET_KB__ KB)를 쓰면 돼요.

3. 개발자 도구 콘솔

리스 탭에서 F12 → Console에 console.js 내용을 붙여넣고 Enter. 크롬이 처음 붙여넣기를 막으면 안내대로 allow pasting을 입력한 뒤 다시 붙여넣어요.
